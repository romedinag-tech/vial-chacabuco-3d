# Av. Chacabuco (Concepción): maqueta conceptual antes y después

Visor 3D web de un rediseño conceptual (prefactibilidad) de Avenida Chacabuco, entre Arturo Prat y Roosevelt.
Botones **ANTES / DESPUÉS** y vistas con nombre. Ilustrativo: medidas y tránsito con supuestos rotulados.

Base: ortofoto, planimetría y modelos de superficie del estudio SECTRA 2024 (Gran Concepción); © colaboradores de
OpenStreetMap (ODbL); fotos de fachadas propias.

https://romedinag-tech.github.io/vial-chacabuco-3d/
